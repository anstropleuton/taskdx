# TaskDX

> *Tasker Deluxe*

TaskDX is just a developer To-Do manager app I made for myself. I wanted to complete some of the pending projects in time... then got carried away with this app lmao

Doesn't matter, I got to learn CRUD and REST and Android App development and Windows App development and Web App development

Hmm no wonder why I take so long to do anything, I am busy with side quests all the time

[TaskDX Server](taskdx-server) Server-side code: uses Vercel Functions (no framework) and Upstash Redis database
[TaskDX Android](taskdx-android) Android-side code: uses Jetpack Compose and Kotlin and Material 3
[TaskDX Windows](taskdx-windows) Windows-side code: uses WinUI 3 and C#
[TaskDX Website](taskdx-website) Website-side code: uses Vite and Svelte
